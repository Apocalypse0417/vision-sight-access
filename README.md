# VisionSight - Source Access

Source code is kept in a **private repository** because it contains proprietary
process data from our partner company.

## Request access

1. Open an Issue in this repository (see the template).
2. Include your name, affiliation and the email linked to your account.
3. We review requests during the event and add you as a collaborator (read access).

Access is granted per account and can be revoked after the event.

## What is public

The runnable application packages and the reviewer kit are available as release
assets in the private repository; the submission PDF describes the architecture.
